# Roadmap

- Phase 0: Discovery and acceptance criteria.
- Phase 1: React and FastAPI foundation.
- Phase 2: PDF upload and parsing.
- Phase 3: PDF rendering and page navigation.
- Phase 4: Fixed-position existing text edit mode, undo/redo.
- Phase 5: Stateless PDF export.
- Phase 6: Hardening, tests, limits, rendering architecture verification, and error handling.
- Phase 7: DOCX support.
- Phase 8: Conversion support.
- Phase 9: OCR, forms, images, annotations, advanced editing.
